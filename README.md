Streamlit app using the Ollama Python SDK. For Ollama Python library references, see `ollama-python-ref/`.

## Description
AI-native applications for personal use (not confined to chat interface). Might currently look similar to imranson/agent-interface but built with more robust and scalable backend, intended for long-term development. 

## Setup

Use the `secret-interface` conda environment:

```bash
conda activate secret-interface
```

## Warnings

Streamlit might silent crash during errors. Rerun script in which case.
